# Security Policy

## Сообщение об уязвимости

Не создавайте публичный issue для уязвимостей. Используйте GitHub Private Vulnerability
Reporting (Settings → Security → Private vulnerability reporting) или напишите мейнтейнеру
напрямую.

В сообщении укажите:

- версию мода и версию NeoForge/Minecraft;
- шаги воспроизведения;
- влияние (утечка токена, обход авторизации, RCE и т.п.);
- при наличии — PoC.

## Область ответственности

Мод отвечает за:

- проверку bearer-токена до входа в мир;
- шифрование токена при передаче клиент ↔ сервер;
- ограничения для неавторизованных игроков (limbo);
- отсутствие паролей и токенов в логах.

Вне области: сам API UnderMine, лаунчер, настройки сторонних прокси/плагинов и
online-mode на сервере.

## Поддерживаемые версии

Поддерживается текущая ветка `main` (NeoForge 1.21.1, 21.1.265).
